# Recruiter Brief

## Short Version

Built a DevSecOps security pipeline lab showing how to automate AppSec checks across source code, dependencies, secrets, containers, DAST, and open-source supply-chain posture.

## Tools Used

- GitHub Actions for CI/CD orchestration.
- CodeQL and Semgrep for SAST.
- Gitleaks for secret scanning.
- Dependabot and Dependency Review for dependency risk.
- Trivy for filesystem and container vulnerability scanning.
- OWASP ZAP for DAST.
- OSSF Scorecard for supply-chain posture.
- Docker for containerized delivery.

## What It Proves

- Can build security controls into developer workflows.
- Understands OWASP Top 10 risks and how to automate checks for them.
- Can explain trade-offs between SAST, DAST, dependency scanning, and supply-chain checks.
- Can write maintainable application code with security defaults.
- Can produce clear documentation for technical and non-technical audiences.
